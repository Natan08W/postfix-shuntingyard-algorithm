# Shunting Yard Algorithm

This project makes use of Djikstra's "Shunting Yard" algorithm to take infix expressions and return postfix expression. 

Logic:
*Take a string input containing a mathematically correct expression
*Tokenise the expression
*Use Djikstra's algorithm to sort the tokenised expression into postfix
*Revert the postfix tokens back into a string
*Return the correct postfix expression as a string*
